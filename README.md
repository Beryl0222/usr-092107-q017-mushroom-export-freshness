# 野生菌出口鲜度链

本仓库记录香格里拉松茸出口鲜度链已确认的领域对象、事件名称、校验方式与事件投影，
供出口企业、属地查检、海关、货代与海外客户系统之间交换一致的数据。

## 资料范围

- `contracts/domain.schema.json`：领域事件信封、聚合类型、26 个事件名称、
  事件级必填字段与枚举（质量原因、冻结原因、加工形态、订单等级等）。
- `data/sample.json`：最小信封本地联调样例。
- `data/sample_chain.json`：覆盖全链的中文端到端样例（采集许可 → 交接 → 物种复核 →
  分级 → 混装/拆箱 → 温控 → 冻结/解冻 → 抽样 → 规则 → 订舱/改约 →
  证书签发/更正 → 出运 → 口岸申报查验放行 → 客户签收 → 菌农结算）。
- `src/validator.py`：单记录信封校验与事件流规则校验。
- `src/chain.py`：把只追加事件折叠为鲜度链状态的投影。
- `tests/`：契约校验与业务规则测试。

## 关键规则

记录一经接收，`event_id`、`occurred_at`、`version` 不得原地改写；更正使用新的后继记录。

- **防重复登记**：`event_id` 全局唯一；跨系统重放同一步骤使用相同的
  `idempotency_key`，重复键被拒绝。
- **版本连续**：同一聚合 `aggregate_id` 内 `version` 从 1 起连续递增，
  重复或跳号均拒绝。
- **全程溯源**：批次以 `sources` 引用原料批次或上一级加工批次，混装
  （多来源）、拆箱（`BATCH_REPACKED` 改变构成，旧构成留存在历史中）和改加工形态
  （`BATCH_FORM_CHANGED`，标识不变）都能按数量比例回溯到菌农与采集区域。
- **按数量冻结**：物种存疑（`SPECIES_DOUBT`）或温度超限（`TEMP_EXCURSION`）
  只对 `HOLD_PLACED.quantity_kg` 指明的数量生效，`available_kg` 只扣减被冻结部分；
  解冻后数量恢复。
- **目的国规则按出运日匹配**：`rule_for(country, 出运日期)` 只选
  `effective_from ≤ 出运日 ≤ effective_to` 的规则版本，与登记/查询日期无关。
- **证书版本不覆盖**：更正必须以新 `certificate_id` 签发并通过
  `supersedes_certificate_id` 引用旧证；旧证标记失效但保留完整版本链
  （如 `C-2026-002 → C-2026-002-R1`）。
- **放行缺口与降级**：`clearance_gaps` 在出运前汇总规则缺失/版本不符、证书缺失/
  覆盖不全、样本未通过、数量冻结、物种存疑、保鲜窗口超限；
  `downgrade_options` 给出可改冷冻/干制的数量与质量原因。
- **订舱重排保护小农**：预约变化后按"剩余保鲜时长（保鲜截止最近者优先）、
  订单等级、舱位"重排；第一轮为小农/合作社批次保留 30% 舱位底线
  （`SMALLHOLDER_PROTECTED_SHARE`），第二轮全体候选再按紧迫度竞争，
  小农批次不会总被大户挤出；装不下的整批标记 `CAPACITY_EXCEEDED` 而非静默丢弃。
- **结算口径**：以客户最终接收重量按溯源比例分摊回菌农，结合质量原因扣款，
  而不是按交接毛重结算。
- **差异化视图**：海关视图按证书列明的实物批次节点核对电子证书、版本链、样本与
  出运日生效规则；客户视图只暴露公开产区名、物种、等级、本出运节点温控与
  有效证书，不含采集点、菌农身份与收购点信息。
